# Mill Creek-AR social media package

This folder contains the reusable social campaign for Mill Creek-AR Learning Center in Accra.

## Campaign message

**Talent is everywhere. Opportunity is not.**

The assets show authentic classroom work and center access, belief, training, opportunity, student dignity, and responsible support. They do not use hardship framing or promise specific student outcomes.

## Deliverables

- 52-second vertical master for Reels, TikTok, Facebook, and YouTube Shorts
- 30-second vertical cutdown
- 16-second vertical cutdown
- 30-second square feed video
- 30-second landscape video for YouTube, LinkedIn, Facebook, and X
- Square, portrait-feed, Story, landscape-link, and YouTube-thumbnail images
- Platform-ready post copy, alt text, hashtags, titles, and publishing notes
- Plain subtitle sidecars and a reproducible FFmpeg render script

All video exports use H.264/AAC MP4, square pixels, 30 fps, burned-in captions, and web-compatible `yuv420p` output. Original classroom footage and narration remain unchanged.

## Publication gate

Before public posting, confirm written guardian/media consent for every identifiable student shown. Re-check any time-sensitive program numbers and donation language against the current approved source of truth. The render package is not authorization to publish.
